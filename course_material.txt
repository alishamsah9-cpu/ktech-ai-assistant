1. Principles of Computer Hardware
Hardware supports information systems and business needs.
This means organizations should choose hardware carefully.
They must think about:
What they need now
What they may need in the future
Whether the hardware can be upgraded later
University example:
A university computer lab should not buy very weak computers if students will later use AI, databases, or design software. They need computers that can be upgraded.
Quick Summary
Hardware must match the organization’s needs today and be flexible enough for future growth.
2. Hardware for Processing
Processing means the computer is working on data.
The main processing part is the CPU.
CPU: Central Processing Unit
The CPU is the “brain” of the computer.
It carries out instructions and controls the work of the computer.
University example:
When a student opens Moodle and uploads a file, the CPU helps run the browser, process the file, and complete the upload.
The CPU has three important parts:
2.1 Control Unit
The control unit tells other parts of the computer what to do.
It does not do calculations itself. It manages the flow of work.
University example:
Think of the control unit like a professor during an exam. The professor tells students when to start, when to stop, and what rules to follow.
2.2 ALU: Arithmetic/Logic Unit
The ALU performs:
Mathematical calculations
Logical comparisons
Example calculations:
10 + 5
80 / 4
Example logical comparisons:
Is the student’s grade above 60?
Is the password correct?
University example:
When Moodle calculates a student’s quiz grade, the ALU helps perform the calculations.
2.3 Registers
Registers are very small, very fast storage areas inside the CPU.
They temporarily hold data while the CPU is working.
University example:
A register is like a student keeping one important number on a sticky note while solving a math problem.
Quick Summary
The CPU processes data. The control unit manages instructions, the ALU calculates and compares, and registers temporarily hold data during processing.
3. Primary Storage / Main Memory
Primary storage is also called main memory or RAM.
It temporarily stores programs and data while the computer is working.
Important point:
Primary storage is temporary. When the computer turns off, the data usually disappears.
University example:
When a student opens Word to write an assignment, the assignment is temporarily held in memory while they work. If the laptop shuts down before saving, the work may be lost.
Binary Data
Computers store data using binary.
Binary means using only two states:
0
1
These can also mean:
Off
On
Each character is represented by bits.
University example:
When a student types the letter “A”, the computer stores it using a pattern of 0s and 1s.
Quick Summary
Primary storage is fast temporary memory used while the computer is running.
4. Secondary Storage
Secondary storage is permanent storage.
It saves data even when the computer is turned off.
Examples:
Hard drives
SSDs
USB drives
Memory cards
DVDs
Magnetic tape
University example:
When a professor saves lecture slides on a USB or hard drive, the files remain there even after the computer shuts down.
Advantages of Secondary Storage
Secondary storage is useful because it is:
Non-volatile
It keeps data after power is off.
High capacity
It can store large amounts of data.
Cost-effective
It is cheaper for storing lots of files.
University example:
A university stores thousands of student records. It cannot keep all of them only in RAM, so it uses secondary storage.
Types of Secondary Storage
Magnetic Tape
Used for backup and archiving.
University example:
A university may keep old student records on backup storage.
Magnetic Disks
Traditional hard drives use magnetic storage.
University example:
Old university office computers may use hard disk drives.
RAID
RAID means using multiple disks together to improve performance or protect data.
University example:
If the university stores exam results, RAID can help protect the data if one disk fails.
Optical Discs
Examples:
CD
DVD
Blu-ray
University example:
Older course materials may be stored on DVDs.
Flash Memory
Examples:
USB flash drive
SD card
SSD
University example:
A student saves a PowerPoint presentation on a USB flash drive.
Quick Summary
Secondary storage keeps data permanently and is used for files, backups, records, and large data storage.
5. Enterprise Storage Solutions
Enterprise storage means storage used by organizations, not just one person.
Universities, companies, and hospitals need large storage systems.
5.1 Attached Storage
Attached storage is connected directly to one computer.
University example:
A professor connects an external hard drive to their laptop.
5.2 NAS: Network-Attached Storage
NAS is storage connected to a network.
Many users can access it.
University example:
Students and professors may access shared course files from a university network drive.
5.3 SAN: Storage Area Network
SAN is a high-speed network used only for storage.
It is more advanced and powerful than NAS.
University example:
A large university data center may use SAN to store Moodle data, student records, and research databases.
NAS vs SAN Simple Difference
NAS is like a shared folder on the network.
SAN is like a powerful storage system built for large organizations.
Quick Summary
Enterprise storage helps organizations store and share large amounts of data safely and efficiently.
6. Data Input
Data input means entering data into a computer system.
There are two types of data:
6.1 Human-Readable Data
This is data humans can understand.
Examples:
Printed forms
Handwritten notes
Student ID cards
Assignment papers
University example:
A paper attendance sheet is human-readable.
6.2 Machine-Readable Data
This is data computers can read directly.
Examples:
Barcodes
QR codes
RFID cards
Magnetic stripe cards
University example:
A student scans their ID card to enter the library. The computer reads the card automatically.
Data Entry vs Data Input
Data Entry
Data entry means converting human-readable data into computer-readable form.
University example:
An administrator types student attendance from paper into Excel.
Data Input
Data input means transferring machine-readable data into the system.
University example:
A student scans a QR code for attendance, and the system records it automatically.
Quick Summary
Data input is how information enters the computer. Human-readable data may need typing, while machine-readable data can be read directly.
7. Input Devices
Input devices allow users to enter data into the system.
7.1 Keyboard and Mouse
These are basic input devices.
University example:
A student types an essay using a keyboard and clicks Moodle links using a mouse.
7.2 Speech Recognition
Speech recognition allows users to speak, and the computer converts speech into text or commands.
University example:
A student uses voice typing to write notes.
7.3 Digital Cameras
Digital cameras capture images or videos as input.
University example:
A student uploads a photo of a lab experiment.
7.4 Terminals
A terminal is a device used to access a computer system.
University example:
A library search computer lets students search for books.
Quick Summary
Basic input devices help users enter text, commands, images, and other data into computer systems.
8. Scanning and Optical Input Devices
These devices read printed or marked information.
8.1 OMR: Optical Mark Recognition
OMR reads marks on paper.
University example:
Multiple-choice exam answer sheets are read using OMR.
8.2 OCR: Optical Character Recognition
OCR reads printed or handwritten text and converts it into digital text.
University example:
A professor scans a printed article, and OCR converts it into editable text.
8.3 MICR: Magnetic Ink Character Recognition
MICR reads special magnetic ink, usually on bank cheques.
University example:
If a university receives cheque payments, the bank may use MICR to process them.
Quick Summary
Scanning and optical devices help computers read marks, text, and special printed information.
9. Card-Based Input Devices
These devices read information from cards.
Examples:
Magnetic stripe cards
Chip and PIN cards
Contactless cards
RFID cards
ATM cards
POS devices
University example:
A student ID card may be used to enter campus buildings, borrow books, or pay for printing.
RFID
RFID means Radio Frequency Identification.
It allows data to be read without physical contact.
University example:
A student taps their ID card at the library gate.
POS Device
POS means Point of Sale.
It is used to process payments.
University example:
A cafeteria uses a POS machine when students pay by card.
Quick Summary
Card-based input devices are used for identification, payments, access control, and tracking.
10. Touch and Pen-Based Input
10.1 Touch Screens
A touch screen allows users to interact by touching the screen.
University example:
A student uses a tablet to open lecture slides.
10.2 Stylus / Pen Input
A stylus allows users to write or draw on a screen.
University example:
A professor writes notes on an iPad during a lecture.
10.3 RFID Readers
RFID readers detect RFID cards or tags.
University example:
A university attendance system reads student ID cards.
Quick Summary
Touch and pen-based input makes interaction easier, especially on tablets and mobile devices.
11. Data Output
Output means the computer shows or produces results after processing.
University example:
After a student submits a quiz, Moodle displays the score. That score is output.
12. Visual Output Devices
12.1 Display Monitors
A monitor shows visual output.
University example:
A professor uses a projector screen to show lecture slides.
12.2 LCD and OLED Screens
These are screen technologies.
LCD screens are common and affordable.
OLED screens usually have better contrast and colors.
University example:
Students may use laptops with LCD screens, while newer tablets may use OLED screens.
Quick Summary
Visual output devices display information so users can see results.
13. Printed and Audio Output
13.1 Printers
Printers produce paper output.
University example:
A student prints an assignment before submitting it.
13.2 Plotters
Plotters print large technical drawings.
University example:
Engineering students may print building plans or design diagrams.
13.3 Headphones / Audio Devices
Audio devices produce sound output.
University example:
A student listens to an online lecture using headphones.
13.4 GPS / Navigation Systems
Navigation systems provide location-based output.
University example:
A new student uses GPS to find the campus building.
13.5 3D Printers
3D printers create physical objects.
University example:
Engineering students print a 3D model for a project.
13.6 E-Book Readers
E-book readers display digital books.
University example:
A student reads a textbook on a Kindle or tablet.
Quick Summary
Output devices can show information on screens, print it on paper, play sound, or even create physical objects.
14. Types of Computer Systems
Computers come in different sizes and strengths.
14.1 Personal Computing Devices
These are used by individuals.
Examples:
Smartphones
Tablets
Laptops
Handheld computers
University example:
A student uses a laptop to write assignments and a phone to check Moodle announcements.
14.2 Thin Clients
A thin client is a simple computer that depends on a server.
It has limited power by itself.
University example:
A computer lab may use thin clients where most processing happens on the university server.
Quick Summary
Personal devices are used by individuals, while thin clients depend on stronger central systems.
15. Business and Enterprise Systems
15.1 Desktop PCs
Desktop PCs are standard computers used in offices.
University example:
Administrative staff use desktop PCs to manage student records.
15.2 Workstations
Workstations are more powerful computers used for specialized work.
University example:
Design students may use workstations for 3D modeling.
15.3 Servers
Servers provide services to other computers.
University example:
Moodle runs on a server so students can access it from anywhere.
Types of servers:
Web Server
Handles websites and web traffic.
University example:
The university website runs on a web server.
Enterprise Server
Stores organizational data and programs.
University example:
The university student information system may run on an enterprise server.
File Server
Stores and manages shared files.
University example:
Professors share lecture slides through a file server.
Email Server
Handles email communication.
University example:
Student and staff emails are managed by an email server.
Quick Summary
Business systems include desktops, workstations, and servers that support daily organizational work.
16. High-Performance Computing
16.1 Mainframes
Mainframes are large computers used for huge amounts of data processing.
They require controlled environments.
University example:
A large university system may use mainframe-style computing to process thousands of student records.
16.2 Supercomputers
Supercomputers are extremely powerful computers used for complex calculations.
University example:
Researchers may use supercomputers for climate research, AI training, or scientific simulations.
Quick Summary
Mainframes and supercomputers are powerful systems used for very large and complex tasks.

Chapter 3 explains the hardware used in information systems.
The chapter starts by showing that hardware must support business and organizational needs. Good hardware decisions should consider both current and future requirements.

Hardware allows information systems to input data, process it, store it, and output useful information.

CHAPTER 4 — SOFTWARE: SYSTEMS AND APPLICATION SOFTWARE
==================================================
1. What is Software?
Software means the programs that tell the computer what to do.
A computer by itself is just hardware: screen, keyboard, CPU, memory, printer, and so on. But hardware cannot work properly without software.
Example:
A university computer lab has computers, keyboards, and screens. But students cannot type assignments unless the computer has software like Windows and Microsoft Word.
Computer program means a set of step-by-step instructions given to the computer.
Example:
When a student clicks “Print,” the program sends instructions to the printer: prepare the document, choose pages, and print.
Quick Summary
Software is the “brain instructions” that make hardware useful.

2. Two Main Types of Software
There are two main types:


System software


Application software


System Software
System software controls the hardware and helps the computer run.
The most important type of system software is the Operating System, or OS.
Example:
Windows, macOS, Linux, and Android are operating systems.
In university life, the OS is like the campus administration. Students and professors may not deal with it directly all the time, but it controls the basic services that allow everything else to work.
Quick Summary
System software runs the computer itself.

3. Application Software
Application software helps users do specific tasks.
Example:
Microsoft Word helps students write assignments.
PowerPoint helps professors create lecture slides.
Excel helps calculate grades.
Moodle helps manage course materials.
Users usually care more about application software because it is what they use directly.
Example:
A student usually says, “I need Word,” not “I need system software.” But Word still needs the operating system to work.
Quick Summary
Application software helps people complete specific work.

4. Operating System
An Operating System is a group of programs that controls the computer hardware and allows applications to run.
It works as a bridge between:


The user


The application software


The hardware


Example:
When a student opens PowerPoint, the operating system helps PowerPoint use the screen, keyboard, mouse, memory, and storage.
Computer System Platform
A computer system platform means the combination of hardware and system software.
Example:
A MacBook with macOS is one platform.
A Dell laptop with Windows is another platform.
Quick Summary
The OS manages the computer and allows applications to work properly.

5. Main Tasks of the Operating System
A. Performing Hardware Functions
The OS helps the computer perform basic actions like:


Reading data


Saving files


Showing information on the screen


Sending work to a printer


Example:
When a student saves an assignment, the OS stores the file on the laptop’s drive.

B. Providing a User Interface
A user interface is how the user communicates with the computer.
There are two main types:
Graphical User Interface — GUI
A GUI uses icons, windows, menus, and buttons.
Example:
Windows desktop, macOS, and phone screens use GUI.
University example:
A student clicks the Moodle icon or opens a folder by double-clicking.
Command-Based Interface
This requires users to type commands.
Example:
Typing commands in Terminal or Command Prompt.
University example:
An IT student may type a command to run a Python file instead of clicking an icon.
Quick Summary
The OS lets users control the computer through either icons or typed commands.

C. Hardware Independence and API
The OS provides hardware independence through an API.
An API is a way for software programs to communicate with the operating system or other software.
Simple meaning:
An API is like a messenger that lets one program ask another system to do something.
Example:
When Moodle uploads a file, it does not need to know every technical detail about your laptop. The OS and APIs help manage that process.
University example:
A professor uploads lecture slides to Moodle. Moodle communicates with the system to store and display the file.

D. Managing Memory
The OS manages memory so programs can run smoothly.
Example:
If a student opens Word, Chrome, Teams, and PowerPoint at the same time, the OS decides how memory is shared.
Quick Summary
The OS controls how programs use the computer’s memory.

E. Managing Processing Tasks
The OS manages the CPU and decides which tasks run.
Important terms:
Multitasking
Multitasking means running more than one task at the same time.
Example:
A student is listening to a Teams lecture, taking notes in Word, and checking Moodle.
Time-Sharing
Time-sharing means the system gives different users or tasks small turns using the processor.
Example:
Many students use a university server at the same time. The server gives each student a small share of processing time.
Scalability
Scalability means the system can handle more users or work when needed.
Example:
During exam week, many students log into Moodle at the same time. A scalable system can handle this without crashing.
Quick Summary
The OS manages many tasks and users so the computer keeps working.

F. Networking Capability
The OS helps the computer connect to networks and the internet.
Example:
A student connects to university Wi-Fi and accesses Moodle.

G. Controlling Access to Resources
The OS controls who can access files, printers, networks, and programs.
Example:
A student cannot access the professor’s private grading files because permissions block them.

H. Managing Files
The OS helps create, save, organize, move, delete, and search files.
Example:
A student saves an assignment in a folder called “BIS Chapter 4.”
Quick Summary
The OS manages hardware, memory, processing, networking, security, and files.

6. Common Operating Systems
Microsoft Windows
Windows is widely used on personal computers.
Example:
Many university computer labs use Windows because students are familiar with it.
Apple macOS
macOS is used on Apple computers.
It is popular in creative fields like media, design, music, and education.
Example:
A media student may use a MacBook for video editing or graphic design.
Linux
Linux is open-source software.
Open-source means the code is available and can be viewed or modified.
Example:
Computer science students may use Linux for programming and server work.
Quick Summary
Different operating systems are used for different needs and environments.

7. Mobile Operating Systems

Phones


Cameras


Smart TVs


Tablets


Examples include:


Android


Windows Mobile


Palm OS


Example:
A student uses Android on their phone to check Teams messages and Moodle announcements.
Quick Summary
Mobile operating systems run smaller devices like phones and tablets.

8. Utility Programs
Utility programs help maintain, protect, and fix computer systems.
They are like support tools for the computer.
Hardware Utilities

The university server needs tools to keep Moodle running smoothly for thousands of students.
Quick Summary
Utility programs help maintain, protect, and improve computer systems.

CHAPTER 5 — ORGANIZING AND STORING DATA
==================================================
1. What is this chapter about?
This chapter explains how businesses store, organize, manage, and use data.
Data is not useful if it is messy. A university may have thousands of students, courses, teachers, grades, attendance records, and payments. If all this information is stored randomly, nobody can find anything.
So, organizations use databases to keep data organized.
University example:
KTECH needs to store student names, IDs, courses, attendance, quiz marks, and final grades. A database helps the university find this information quickly.
Quick summary:
This chapter is about using databases to store data properly so organizations can make better decisions.
2. Database
A database is an organized collection of data.
It is the center of almost every information system.
The most common type is a relational database.
A relational database stores data in related tables.
University example:
A university database may have:
Table	What it stores
Student table	Student ID, name, phone number
Course table	Course code, course name
Grade table	Student grades
Teacher table	Teacher name and department
These tables are connected.
Quick summary:
A database is like a digital filing cabinet where information is stored in an organized way.
3. Relational Database
A relational database is made of tables.
Each table stores data about one thing.
Important words:
Table
A table stores information in rows and columns.
University example:
A Student table stores all student information.
Record
A record is one full row in a table.
University example:
One student’s full information is one record.
Field
A field is one specific piece of information.
University example:
Student ID, student name, phone number, and email are fields.
Entity
An entity is something important that we want to store data about.
University example:
Student, course, professor, classroom, and assignment are entities.
Example:
Student_ID	Name	Course
1001	Ahmed	BIS
1002	Fatima	OOSAD
Here:
Student is the entity.
Each row is a record.
Student_ID, Name, and Course are fields.
Quick summary:
A relational database organizes data into tables. Tables contain records, and records contain fields.
4. Primary Key
A primary key is a field that makes each record unique.
No two records should have the same primary key.
University example:
Student ID is a primary key because every student has a different ID.
Two students may have the same name, but they cannot have the same Student ID.
Example:
Student_ID	Name
1001	Ali
1002	Ali
The names are the same, but the Student_ID is different.
Quick summary:
A primary key is the unique identifier for each record.
5. Foreign Key
A foreign key is a primary key from one table used inside another table.
It connects tables together.
University example:
The Student table has Student_ID as the primary key.
The Grade table also uses Student_ID to show which student received which grade.
Student table:
Student_ID	Name
1001	Ali
Grade table:
Grade_ID	Student_ID	Grade
1	1001	90
Here, Student_ID in the Grade table is a foreign key.
Quick summary:
A foreign key connects one table to another table.
6. Referential Integrity
Referential integrity means the database must stay logical and correct.
You cannot refer to something that does not exist.
University example:
You cannot enter a grade for Student_ID 9999 if there is no student with ID 9999 in the Student table.
This prevents mistakes.
Quick summary:
Referential integrity protects the database from incorrect relationships.
7. Database Design
Database design means planning the database before building it.
It is also called a data model or database schema.
A database design includes:
Tables
Fields
Primary keys
Foreign keys
Relationships between tables
There are four main stages:
1. Identify entities
Find the important things you need to store.
University example:
Students, courses, teachers, classrooms, and grades.
2. Identify relationships
Find how these things are connected.
University example:
A student registers in many courses.
A professor teaches many students.
3. Identify attributes
Attributes are details about each entity.
University example:
Student attributes: ID, name, email, phone number.
4. Resolve relationships
Decide how tables will connect using primary keys, foreign keys, or linking tables.
University example:
Because many students can take many courses, we may need a Registration table to connect students and courses.
Quick summary:
Database design is like drawing the plan before building the database.
8. Business Rules
Business rules explain how the organization works.
They control relationships in the database.

Receiving Device

The professor’s laptop receives the email.

Speed

Telecommunication works by sending a message from one device to another through a communication medium.

CHAPTER 7 — OPERATIONAL SYSTEMS
==================================================
1. What are Operational Systems?
Operational systems are information systems that help an organization run its daily activities.
Simple meaning:
They help the business do normal work every day, such as selling, buying, paying employees, serving customers, and recording money.
University example:
At a university, daily operations include registering students, recording attendance, collecting tuition fees, giving grades, and printing transcripts. These activities need systems to manage them.
Examples of operational systems:
Transaction Processing Systems (TPS): record daily transactions.
Supply Chain Management systems: help with purchasing and supplies.
Customer Relationship Management (CRM): help manage customers or students.
Accounting systems: record payments, invoices, salaries, and tax records.
Quick summary:
Operational systems are the “daily work systems” of an organization.
2. Transaction Processing Systems (TPS)
A Transaction Processing System is a system that records and processes detailed business activities.
A transaction means one business event.
Simple meaning:
Every time something happens in the organization, the TPS records it.
University example:
When a student pays tuition, registers for a course, borrows a library book, or submits an online assignment, each action is a transaction.
TPS examples:
Order entry
Payroll
Inventory control
Accounts receivable
Accounts payable
General ledger
University example:
Payroll: paying professors and staff.
Inventory: tracking computers in labs.
Accounts receivable: tracking student tuition payments.
General ledger: keeping the university’s main financial records.
Quick summary:
TPS records small but important daily activities.
3. Why TPS is Important
TPS is important because it updates organizational records.
Simple meaning:
The system keeps the organization’s information current.
University example:
If a student pays tuition today, the system should immediately update the student’s account so the finance office knows the payment was made.
TPS supports other systems such as:
MIS: Management Information Systems
DSS: Decision Support Systems
Special-purpose systems
University example:
The university management may use reports from TPS to know how many students registered, how much money was collected, and how many classrooms are needed.
Quick summary:
TPS is the foundation. Other systems depend on TPS data.
4. Types of TPS Processing
A. Batch Processing
Batch processing means transactions are collected first, then processed later as a group.
Simple meaning:
The system waits and processes many transactions at one time.
University example:
The university may collect all part-time lecturers’ teaching hours during the week, then process payroll at the end of the week or month.
Business examples:
Daily invoicing
Weekly payroll
Advantage:
Good when immediate processing is not required.
Disadvantage:
Data is not updated instantly.
B. Online Transaction Processing (OLTP)
OLTP means each transaction is processed immediately.
Simple meaning:
The system updates data in real time.
University example:
When a student registers for a class online, the available seat count changes immediately. If the class has 30 seats and one student registers, it becomes 29 seats instantly.
Business examples:
Airline booking
Stock trading
Online shopping
Package tracking
Advantage:
Data is always up to date.
Disadvantage:
The system must be fast and reliable.
Quick summary:
Batch processing happens later. OLTP happens immediately.
5. Objectives of TPS
TPS has several objectives.
1. Process transaction data accurately
The system must record correct information.
University example:
If a student pays 100 KD, the system must not record it as 10 KD.
2. Avoid fraud
The system should help prevent cheating or illegal actions.
University example:
Only authorized staff should be able to change student grades or payment records.
3. Produce timely reports
The system should create reports quickly.
University example:
The head of department may need a report showing how many students are registered in each course.
4. Increase labor efficiency
The system should reduce manual work.
University example:
Instead of manually counting attendance papers, the LMS can calculate attendance automatically.
5. Improve customer service
The system should help serve users better.
University example:
Students can check their grades, schedules, and payments online instead of visiting many offices.
6. Build loyalty and competitive advantage
Good systems make people trust and prefer the organization.
University example:
If students can register easily, receive fast support, and access records online, they may feel the university is organized and professional.
Quick summary:
TPS improves accuracy, speed, security, service, and efficiency.
6. Transaction Processing Cycle
The transaction processing cycle has six steps:
Data collection
Data editing
Data correction
Data manipulation
Data storage
Document production
Think of it like this:
A student pays tuition → system collects data → checks it → fixes errors → calculates balance → stores it → prints receipt.

Chapter 13: Management Information Systems
1. What is a Management Information System?
A Management Information System, or MIS, is a system that helps managers make decisions by giving them useful information.
It collects data, processes it, and turns it into reports.
University example:
A professor has marks for quizzes, assignments, attendance, and exams. Alone, these are just data. An MIS can turn them into a report showing which students are passing, failing, or need support.
Quick summary
MIS helps managers understand what is happening and make better decisions.
2. Data vs Information
Data means raw facts.
Information means data that has been organized and made useful.
University example:
“Ali: 7/10, Sara: 9/10, Ahmed: 4/10” is data.
A report saying “30% of students failed Quiz 1” is information.
Quick summary
Data is raw. Information is useful and meaningful.
3. Why managers need information
Managers need information to plan, control, and make decisions.
Planning means deciding what to do in the future.
Controlling means checking if things are going correctly.
Decision-making means choosing the best action.
University example:
If many students fail Chapter 6 quiz, the course coordinator may decide to add a revision class.
Quick summary
Managers use information to understand problems and choose solutions.
4. Types of decisions
Structured decisions
These are routine decisions with clear steps.
University example:
If a student gets below 60%, the system marks them as failing.
Semi-structured decisions
Some parts are clear, but human judgment is still needed.
University example:
A professor decides whether to give extra revision based on grades and student participation.
Unstructured decisions
These are complex decisions with no fixed answer.
University example:
The university decides whether to create a new AI course. This needs research, opinions, cost analysis, and planning.
Quick summary
Some decisions are easy and repeated. Others need more thinking and judgment.
5. Levels of management
Operational level
This is the lowest level. It deals with daily tasks.
University example:
Recording attendance, entering quiz marks, and booking classrooms.
Tactical level
This is middle management. It focuses on short-term planning.
University example:
A department head checks student performance and decides whether to change teaching methods.
Strategic level
This is top management. It focuses on long-term goals.
University example:
The university decides to open a new college or invest in AI learning tools.
Quick summary
Operational = daily work.
Tactical = department planning.
Strategic = long-term direction.
6. Types of information systems
Transaction Processing System — TPS
A TPS records daily transactions.
University example:
When students register for courses, pay fees, or submit assignments, the system records those actions.
Management Information System — MIS
MIS uses TPS data to create reports for managers.
University example:
The system creates a report showing average grades for each course.
Decision Support System — DSS
A DSS helps managers analyze different options.
University example:
The university uses a system to compare whether online classes or face-to-face classes improve student results.
Executive Information System — EIS
An EIS gives top managers simple summaries and dashboards.
University example:
The dean sees a dashboard showing enrollment numbers, graduation rates, and student satisfaction.
Quick summary
TPS records daily actions.
MIS creates reports.
DSS helps analyze decisions.
EIS gives summaries for senior leaders.
7. Reports in MIS
MIS usually produces reports.
Scheduled reports
These are produced regularly.
University example:
A weekly attendance report.
Exception reports
These show unusual problems.
University example:
A report showing students who missed more than 3 classes.
Demand reports
These are created when someone asks for them.
University example:
A professor asks for a report showing only students who scored below 50%.
Drill-down reports
These let managers go from general information to detailed information.
University example:
The dean sees that Business students have low grades, then clicks to see which course caused the problem.
Quick summary
MIS reports help managers see regular updates, problems, specific requests, and details.
8. Dashboards
A dashboard is a visual screen showing important information quickly.
It may include charts, numbers, warnings, and summaries.
University example:
A course dashboard shows attendance percentage, average quiz score, missing assignments, and failing students.
Quick summary
Dashboards help managers understand information quickly without reading long reports.
9. Key Performance Indicators — KPIs
A KPI is a measurement used to check performance.
University example:
Student attendance rate, pass rate, assignment submission rate, and course satisfaction score are KPIs.
Quick summary
KPIs show whether an organization is doing well or not.
10. Benefits of MIS
MIS helps organizations by improving decisions, saving time, reducing mistakes, and giving managers better control.
University example:
Instead of manually checking every student’s marks, the system automatically shows which students are at risk.
Quick summary
MIS makes work faster, clearer, and more accurate.
11. Problems or limitations of MIS
MIS is not perfect.
It depends on accurate data. If the data is wrong, the reports will also be wrong.
University example:
If attendance is entered incorrectly, the report may wrongly show that a student is absent too much.
MIS can also be expensive, difficult to use, or ignored by staff.
Quick summary
MIS is useful, but only if the data is correct and people use it properly.
Full Chapter Summary
Chapter 13 explains how Management Information Systems help organizations manage information and make decisions. Data by itself is just raw facts, but when it is organized, it becomes useful information. Managers need this information to plan, control, and solve problems.
Different levels of management need different information. Operational managers need daily details, tactical managers need reports for planning, and strategic managers need summaries for long-term decisions. Systems like TPS, MIS, DSS, and EIS support these different needs.
MIS produces reports, dashboards, and KPIs that help managers understand performance. In a university, this could mean tracking attendance, grades, student progress, course performance, and department results.
The main idea is simple: MIS turns data into useful information so managers can make better decisions.
